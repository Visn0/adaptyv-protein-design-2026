# C5 — minibinders

**Strategy**: every design so far is a 60-110 residue chain. Short, stiff
binders (30-50 aa) are cheaper to make, easier to keep folded, and their
small interface concentrates on fewer contacts — precision over surface.

**Tools**: the hosted RFD4 NIM with the MINI set (same ridge hotspots as
the main funnel, binder length 30-50), the standard screens.

**Pipeline**: 160 designs generating now (mini-wave1) -> s0 pose screen ->
G12D folds -> tri-state for the winners.

**Results** (2026-11-01/02): 37 designs folded, **11 JDI-like (30%)**, 3 strict passers. mini-wave1 run-011 design_0001 carries the strongest free-state dependence in the project (dfree +0.701; its child +0.752). The short format is viable.

**Why it may work**: the challenge allows 10-250 aa; nothing forces large
binders. A 30-50 aa design that reads P4-P8 is a sharper tool, and short
chains are the classic format for chemical synthesis and cheap testing.
